Each icon is the mark centred with 10% padding on all sides, so it survives the rounded-corner masks Android and iOS apply. At 32px the chart bars and the arc gap are near their legibility floor — if the favicon reads muddy in use, that is the size to redraw first.

Misuse
Never stretch. Scale both axes together.
Never place the full-colour mark on teal. The arc disappears.
On ink, use the light version. The K vanishes otherwise.
Never rotate, and never recolour the teal.
File formats
The mark is now vector: SVG for screen, EPS for print, plus one-colour versions for embroidery, stamps and single-plate printing. Flat colour replaces the gradients in the original artwork, which is what lets it hold at 24px. The wordmark inside the SVG lockups references Bricolage Grotesque by name rather than carrying outlines — convert it to paths before sending artwork to anyone who does not have the font. PNG rasters are still in the folder for tools that will not take SVG.
